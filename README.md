# 东芽果 DYG

一个页面，两种形态：浏览器起始页 ⇄ 博客。

打开是起始页（刊头、圆环时钟、搜索、21 个收藏），右上角切到博客。
两者共用一条导航栏和同一个 `<audio>`，站内跳转是路由，不整页刷新，音乐不断。

## 特性

- **两套骨架**：起始页是 620px 窄栏报纸版式；博客是顶部胶囊 + 通栏大图
- **三套皮肤**：报纸（默认）/ 夜幕 / 新拟物，按钮循环切换，记忆在 localStorage
- **圆形揭示转场**：换页和形态切换共用一个 `clip-path` 波纹，圆心跟着点击位置
- **站内路由**：`fetch` + `DOMParser` 只替换内容区，View Transition 做过渡

## 本地运行

双击仓库根目录的 `启动网站.bat`（需要 Node.js），会用本地服务打开
`http://127.0.0.1:4700/blog-v6/`。

> 直接双击 `index.html`（`file://`）也能看，但浏览器禁止页面间 `fetch`，
> 站内跳转会退化成整页刷新，过渡动画不会出现。

## 说明

纯静态，无构建步骤。样式令牌在 `theme.css` 顶部的 `:root` 与三个
`html[data-theme=...]` 段里。
